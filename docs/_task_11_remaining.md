| 词 | 白话解释 |
|---|---|
| NACA | 美国国家航空咨询委员会。它给出的翼型族命名与生成公式至今仍在用，四位族用三个数字描述，五位族用四个数字描述 |
| RANS | 雷诺平均纳维-斯托克斯方程。把湍流脉动做时间平均之后的流体方程，工程上最常用的湍流数值求解方法 |

| 局部马赫数 | 当地流速与声速之比。超过 1 是超音速 |

## 四、流场图注跟着变量切换

`src/pages/Forward.tsx` 里流场云图下面的图注现在是固定一句
「流场由 b_field.onnx 在浏览器内推理，再乘场模态基还原，单位与论文图一致。」
改成跟着当前选中的物理量切换，四种分别写：

- **u**：流向速度，沿来流方向的速度分量，单位米每秒。翼型上方气流加速，下方减速，尾迹里出现速度亏损。
- **v**：横向速度，垂直于来流方向的速度分量，单位米每秒。绕流时气流被抬起或压下，所以翼型上下两侧符号相反。
- **p**：压力，这里用的是运动学压力，即压强除以密度，单位平方米每秒平方。翼型上方的负值区就是吸力区，是升力的主要来源。
- **nu_t**：涡黏系数，湍流模型里表示湍流掺混强度的量，单位平方米每秒。它在近壁与尾迹里最大，也是四个场里最难预测的一个。

四种图注末尾都补一句：由 `b_field.onnx` 在浏览器内推理，再乘场模态基还原，单位与论文图一致。

变量与图的对应关系在 `src/pages/Forward.tsx` 里的 `FIELD_META` 常量，
把说明文字挂在它上面即可。

## 五、降维演示显示体积与点数

`src/pages/Mor.tsx` 里选中样本的信息区，增加两栏对照。

**数据来源**：`samples.json` 里每条样本现在有四个新字段，直接用，不要写死常数。

| 字段 | 含义 |
|---|---|
| `bytesVol` | 该样本内部体积文件 internal.vtu 的字节数 |
| `nVol` | 该样本网格点数 |
| `bytesSurf` | 表面文件 aerofoil.vtp 的字节数 |
| `nSurf` | 表面点数 |

**第一栏 原始样本**，显示该样本的实际值，例如
「内部体积文件 14.35 MB，181794 点；表面文件 0.06 MB，1025 点」。
再注明一句：本次降维只用表面文件，体积文件没有进网页。

**第二栏 降维结果**，显示：
压力曲线用 8 个模态坐标表示，8 个 float32 就是 32 字节；
乘的曲线基是 8 乘 256 个 float32，约 8 KB，这份基全部样本共用，不按样本重复计；
样本自己的几何 128 维是 512 字节。

**再给一句对比**：一条样本的表面文件约 0.06 MB，压到 8 个坐标只有 32 字节，
加上共享的基也只占几十 KB。
