# 可交互演示作品：项目计划（第 1 轮骨架）

## 1 目标与交付物

交付一个可交互网页作品与论文、演示记录。网页有四个页面：前向预测、
降维演示、反向设计与对话、成果总览。全部模型推理在浏览器里完成，
不依赖服务器。总容量不超过 200 MB；按 DEMO_RESEARCH 的口径，
实际资产预计在 44 到 56 MB，留有充足余量。

## 2 技术选型

- 页面框架：Vite + React + TypeScript（构建产物小、开发快）。
- 三维与场渲染：Three.js（翼型剖面、流场云图、尾迹）。
- 二维图表：ECharts（折中前沿、收敛曲线、多解性散点）。
- 模型推理：ONNX Runtime Web（WASM 或 WebGPU 后端），在浏览器里跑
  压力曲线模型与流场模型，单次推理在毫秒到秒级。
- 大模型对话：可选在线接口（Cloudflare Worker 或 Vercel 函数，只做
  自然语言转结构化参数与工具调用）；离线时用关键词解析加预计算结果
  兜底，保证演示永不空转。
- 整个演示是静态站，可以双击本地文件或静态服务器直接打开。

## 3 四个页面的功能与交互

### 3.1 前向预测
用户拖动四个生成参数（弯度大小、弯度位置、弯型、厚度）与攻角，
右侧实时给出翼型剖面、压力曲线（256 点）、压力场与速度场云图、
升力与带内损失。改参数到出图的目标延迟是 100 毫秒以内。
数据文件：b_cp.onnx、b_field.onnx、field_basis.bin、grid.json、cp_basis.json。

### 3.2 降维演示
用户从内置 1000 条真实样本里选一条，或粘贴 / 上传一条 AirfRANS
数据，实时显示主成分坐标、重构曲线（或重构流场）、逐点误差、
每个模态的贡献。数据文件：cp_basis.json、samples.json、field_basis.bin。

### 3.3 反向设计与对话
左侧对话框，右侧结果面板。用户说"设计一个 8 度附近升力尽量高、
10 度也别掉的翼型"，接口把这句话转成结构化目标，调用工具
search_design（在预计算前沿里检索或局部搜索）、invert_pressure（按
目标压力曲线反演）、explain_case（给出形状与流场）。未填写设置时
自动使用本地规则模式。数据文件：results.json、invert_*.json。

### 3.4 成果总览
把论文图表做成可交互画廊：折中前沿（悬停看形状与流场）、收敛曲线
（可播放）、五个案例对比、反演多解性散点、模型可信度核对、数据集
体检统计。每张图配简短说明与数据来源。数据文件：results.json、图片目录。

## 5 设置面板与密钥规则

1. 现场输入，现场使用。用户填写接口地址、模型名称与 API key，
   填完立刻生效，不需要重启页面。
2. 绝不保存到本地。不写 localStorage、sessionStorage、IndexedDB、
   Cookie、文件；只放在内存里的一个变量。
3. 关闭即丢弃。页面关闭或刷新后，key 与配置全部消失；界面上明确
   写一行提示。
4. 仓库零泄露。代码里不出现默认 key、占位 key 或示例 key；提交前
   扫描源码与构建产物；设置面板默认留空，未填写时对话功能显示
   "请先在设置里填写自己的接口信息"，并自动使用离线兜底模式。
5. 可选的本地方案。设置面板可切换"仅本地规则模式"，用关键词解析
   加预计算结果完成演示，此时不需要任何 key。

记录一并交付；离线包与公网地址都给出。

## 8 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 原始数据被误打包 | 超过 200 MB | 打包脚本写死排除清单，打包后自动核对总容量与文件数 |
| 浏览器性能不足 | 拖参数卡顿 | 模态基只上传一次，拖动时只更新系数；场渲染用着色器；预计算能预计算的 |
| 大模型接口密钥泄露 | 被滥用 | 密钥不落盘、不进仓库；设置面板现场填写，只存内存，关闭即丢 |
| 接口不可用 | 对话页面变砖 | 关键词解析加预计算兜底，页面显示当前是在线还是降级模式 |
| 评委机器不能联网 | 演示打不开 | 交付包带构建好的 dist/，本地静态服务即可离线运行 |
| 数据集不可打包 | 降维演示缺输入 | 内置 1000 条真实样本（约 4 MB），原始 .vtu 让用户自备 |
| 中文在图中显示成方块 | 观感差 | 网页用系统字体加内置子集字体；图片已在本地用中文字体重绘过 |
| 三个模型版本混淆 | 结论对不上 | 前端展示每个模型的口径与精度，注明绝对升力未经验证 |
