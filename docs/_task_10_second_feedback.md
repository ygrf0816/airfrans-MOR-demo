## 一、前向预测页的版面与流场比例

用户的原话是：流场云图上下有黑边；要把流场云图那个矩形框横向拉长，
宽度等于"压力系数曲线的框加翼型形状的框再加中间间隙"；上边界往下调，
让压力曲线框与翼型形状框一样大。

改成这样：

- 中间与右侧区域改成一个两行的嵌套网格。
  第一行两块并排，左边翼型形状，右边压力曲线，**两块高度必须相等**。
  第二行放流场云图，**横跨上面两块的宽度加中间的间隙**。
- 左栏的形状参数与最右一列的指标卡不受影响，仍各占一列。
- 流场云图的高度按画布宽度与窗口长宽比算出来，让画面正好填满，不留黑边。

**黑边的真正原因已查到**，不要靠调高度去凑。数据集掩膜是一千条样本计算域的并集，
最外侧那几行本来就没有有效格。实测各行的有效率：

| 法向范围 | 最小行有效率 |
|---|---|
| ±1.65（整域） | 0.000，最外几行完全没数据 |
| ±1.50 | 0.969 |
| ±1.40 | 0.980 |
| ±1.20 | 0.988 |

所以把流场默认窗口的法向范围改成 **负 1.50 到 1.50**，
横向交给现在已有的一比一等比适配去定，黑边就没了。
窗口右下角那行坐标提示保留，方便核对。

## 四、行话与图注

### 4.1 补名词解释

全站扫一遍，凡是第一次出现就加一句白话解释。至少要覆盖这几个：

- **NACA**：美国国家航空咨询委员会，它给出的翼型族命名与生成公式至今仍在用，
  四位族用三个数字描述，五位族用四个数字描述。
- **RANS**：雷诺平均纳维-斯托克斯方程，把湍流脉动做时间平均之后的流体方程，
  工程上最常用的湍流数值求解方法。
- **MOR / POD**：用少数几个模态表示一整条曲线或一整个场，属于降维方法。
- **攻角**：来流方向与翼型弦线的夹角，单位度。
- **雷诺数**：惯性力与黏性力之比，用来刻画流动状态。
- **压力系数 Cp**：表面静压除以来流动压，无量纲量。
- **代理模型**：用一个小的数学模型代替昂贵的数值求解，速度快但精度有限。
- **局部马赫数**：当地流速与声速之比。
- **分离**：边界层脱离壁面，升力骤降阻力骤增。

可以在主页的单列一块"名词解释"，也可以在各页首次出现处加括号说明，你选一种做到位。

### 4.2 流场图注跟着变量切换

现在是固定一句话。改成跟着上面选中的量切换，例如：

| 量 | 图注 |
|---|---|
| u | 流向速度，沿来流方向的速度分量，单位米每秒。翼型上方加速、下方减速，尾迹里出现亏损。 |
| v | 横向速度，垂直于来流方向的速度分量，单位米每秒。绕流时气流被抬起或压下，所以上下两侧符号相反。 |
| p | 压力，这里用的是运动学压力，即压强除以密度，单位平方米每秒平方。翼型上方的负值区就是吸力区，是升力的主要来源。 |
| nu_t | 涡黏系数，湍流模型里表示湍流掺混强度的量，单位平方米每秒。它在近壁与尾迹里最大，也是四个场里最难预测的一个。 |

最后都补一句：由 `b_field.onnx` 在浏览器内推理，再乘场模态基还原，单位与论文图一致。

### 4.3 说明四个阈值的出处

用户问这四个约束是哪里来的。在指标卡旁边的说明里逐条写清楚：

- **八度升力参照线 1.146**：官方数据库里同口径八度升力最高的真实翼型，
  用来判断是否超过了现有最好的真实样本，不是硬约束。
- **带内损失**：管线里它是**优化目标之一**，不是硬约束。
  把卡片上原来那条 0.3 的线改成 **0.367**，并标注"参照：数据库带内最优"。
  搜索解的实际带内损失落在 0.359 到 0.938 之间。
- **局部马赫数上限 0.6**：工程上的保守上限，这一带翼型马赫数超过 0.6 之后
  激波与阻力增长很快。
- **分离代理上限 0.007874**：在 511 条五位族真实样本上标定，
  取分离代理的九十分位，正好等于一个离散热度步长，也就是"最多一格平坦"。

这块数字必须与 `results.json` 里的 `objective` 一致，不要自己编。

## 五、降维演示显示体积与点数

`samples.json` 的每条样本现在已经多了四个字段，直接用：

| 字段 | 含义 |
|---|---|
| `bytesVol` | 该样本内部体积文件 internal.vtu 的字节数 |
| `nVol` | 该样本网格点数（约十八万） |
| `bytesSurf` | 表面文件 aerofoil.vtp 的字节数 |
| `nSurf` | 表面点数（约一千） |

平均下来内部体积文件 14.20 MB、179776 点；表面文件 0.06 MB、1010 点。

在选中样本的信息区显示两栏对照：

- **原始样本**：内部体积文件多少 MB、多少点；表面文件多少 MB、多少点。
  注明本次降维只用表面文件，体积文件没进网页。
- **降维结果**：压力曲线用 8 个模态坐标表示，8 个 float32 就是 32 字节；
  再乘以共享的曲线基 8 乘 256 个 float32，约 8 KB；
  样本自己的几何 128 维是 512 字节。模态基是全部样本共用的，不按样本重复计。
- 给一句对比：一条样本的表面文件约 0.06 MB，压到 8 个坐标 32 字节，
  加上共享的基也只占几十 KB。

数字全部从 `samples.json` 现取，不要写死常数。
