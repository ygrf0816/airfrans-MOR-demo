## 硬规矩

1. 不许改上面列的任何一个已完成的文件。需要新的工具函数就新建文件。
2. 每个页面一个文件写完，不要一次写四个。写完一个存一个。

4. 顺序是 前向预测、降维演示、反向设计、成果总览。按这个顺序做，

## 数据怎么读

`data` 这个属性里已经有 `grid`、`cpBasis`、`samples`、`results`、`mode`、`missing`。
另外几个二进制文件要自己取，取法是 `fetch(assetUrl('xxx.bin'))` 再 `arrayBuffer()`，
用 `new Float32Array(buf)` 直接映射，不要转成普通数组。

- `samples_cp.bin`，float32，一千行乘 256 列，第 i 行是第 i 条样本的真实压力曲线。
- `samples_geom.bin`，float32，一千行乘 128 列，第 i 行是原始几何曲线。
- `samples_alpha.bin`，float32，一千行乘 136 列，前 8 列是压力曲线模态坐标，
  后 128 列是流场模态坐标。
- `cases_field.bin` 与 `cases_field.json`，七个案例的四个流场，按 json 里的 blocks 切块。
- `field_basis.bin` 与 `field_basis.json`，流场模态基与物理单位换算系数。
- `figs/index.json`，画廊的图名与说明。

数据文件读不到时不要崩，也不要留白，用 `mock.ts` 里的解析近似顶上，
并在页面上标出当前是示例模式。

## 页面要做成什么样

### 前向预测（最重要，先做）

三栏布局。左栏是控件，族别切换四位或五位，五位给 L、P、Q、T，四位给 M、P、T，
再加攻角与来流速度。每个控件旁边显示当前数值和一句影响说明。

中栏画翼型轮廓。横轴按弦长归一化，画上弦线与弯度线，前缘做个标注。
用 `nacaOutline` 拿轮廓点，画成闭合路径，底下填一层渐变。
参数一动形状要连续变化。

右栏上半是压力曲线。横轴是归一化弧长 s，从 0 到 1。纵轴是 Cp 并且要反过来，
负值在上。曲线底下填渐变。再给一个切换按钮，把闭环曲线折成上下表面两条弦向曲线叠画，
折法就是取下标的 0 到 127 与 127 到 255 两段。

右栏下半是流场云图。四个物理量 u、v、p、nu_t 可以切换。
用 canvas 画，按 `grid.json` 的掩膜把无效格留黑，翼型位置描一条白边，
边上给一条竖直的色标并标出单位。

底部一排四张指标卡。八度升力、带内损失、局部马赫数代理、分离代理。
每张卡画一条约束线，超限就换成警告色并写出超了多少。
数值用 `predictCp` 得到的曲线做压力项积分算，或者先用 `results.json` 里的
`objective` 与 `grid` 做近似，并在卡上标明数值来源。

性能要求，拖动滑块到画面更新在 100 毫秒以内。128 维几何只在参数改变时算一次并缓存。

### 降维演示

上排是样本选择器，支持按名字搜、随机抽、按攻角与雷诺数筛。
选中后显示真实曲线、几何形状与官方升力。

中间给秩的滑块，1 到 8。用 `cpBasis` 与 `samples_alpha.bin` 的前 8 列做重构，
真实曲线与重构曲线叠画，下面画一条逐点误差带。秩变化时曲线要连续变化。

右侧列八个模态，每个一条缩略曲线与一根贡献条。点某一条就把这条模态单独加上去看效果。
再加一条累计能量曲线并标出当前秩。

底部做上传区。支持拖入 json 或 csv，csv 的列名写成 `name,uInf,aoa,s,cp`。
解析后按同一套基投影，显示坐标与重构误差。格式不对时给人看得懂的错误提示。
转换脚本是 `04_results/demo/tools/airfrans_to_web.py`，在页面上写清用法。

### 反向设计与对话

左栏聊天区，气泡、时间、底部输入框、回车发送。
右栏上面是三步状态块，解析需求、检索候选、出形状与流场确认，
发一句话之后依次从等待变完成。这是这个页面最重要的观感。

结果区给四个参数值、翼型形状、压力曲线、三项约束通过情况，再加一个备选列表可以点着换。

设置面板已经在 `SettingsPanel.tsx` 里了，直接用它，不要重写。
没填接口信息时走本地规则模式，用 `results.json` 的 `llmTools` 里的关键词表与预置方案，
从 `fronts` 与 `presets` 里挑候选，再用 `predictCp` 算一遍确认。
右上角角标显示当前是在线模式还是本地规则模式。
