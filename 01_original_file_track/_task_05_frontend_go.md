### 第三步 四个页面

**前向预测。** 左边族别切换加参数滑块（五位给 L、P、Q、T，四位给 M、P、T，
再加攻角与来流速度）。中间画翼型轮廓与弯度线。右上画压力曲线，横轴是弧长 s，
纵轴反过来，负值在上，底部填渐变，另给一个切换折成上下表面两条弦向曲线。
右下画流场云图，四个量可切，掩膜外留黑，翼型描白边，带色标与单位。
底部四张指标卡显示八度升力、带内损失、马赫代理、分离代理，并标出约束线与是否越线。
若 `b_cp.onnx` 与 `b_field.onnx` 与 `cp_basis.json` 都在，就用 onnxruntime-web 跑真模型，
先用统计量做 z-score 再拼 133 维，输出低维坐标后乘基加均值还原；
文件不全就退回到用 `results.json` 里前沿数据的近似插值，并在界面上写明当前是近似模式。

**降维演示。** 上面一排说明与样本选择器，支持搜名字、随机抽、按攻角与雷诺数筛。
中间给秩的滑块一到八，显示真实曲线与重构曲线叠画，加逐点误差。
右边列八个模态的缩略曲线与贡献条，点某个模态可以把这条模态单独加上去看它修了什么，
再加一条累计能量曲线并标出当前秩。
底部做上传区，支持拖入 `samples.json` 那种结构或列名为 `name,uInf,aoa,s,cp` 的 CSV，
解析后按同一套基投影，显示坐标与重构误差，格式不对时给人看得懂的错误。
附带的转换脚本是 `04_results/demo/tools/airfrans_to_web.py`，界面上写清楚它的用法。

**反向设计与对话。** 左边聊天区，气泡、时间、底部输入框、回车发送。
发一句话之后右侧依次出现三步状态块，解析需求、检索候选、出形状与流场确认，
每一步从等待变完成。结果区给四个参数值、翼型形状、压力曲线、三项约束通过情况，
再加一个可以点着换的备选列表。
右上角设置面板按原来的要求做，现场填写，只放内存，关掉即丢，界面上写清这一点，
代码里不许出现任何默认或示例密钥，不许写 localStorage、sessionStorage、IndexedDB、Cookie。
没填时走本地规则模式，用 `results.json` 的 `llmTools` 里的关键词表与预置方案出结果，
右上角用徽标显示当前是在线模式还是本地规则模式。

**成果总览。** 画廊用 `figs/index.json`，图片按标题与说明排列，加载失败时显示图名。
再加两个可交互视图，折中前沿散点用 `results.json` 的 `grid` 与 `fronts`，
横轴带内损失、纵轴八度升力，悬停显示参数与小缩略图，把数据库最优与上界画成参考线；
收敛回放用 `history` 数据，带播放按钮与进度条，三个种子分别一条。
再加数据集体检卡片区，样本数、族别比例、攻角分布、雷诺数分布、四个划分的规模。
