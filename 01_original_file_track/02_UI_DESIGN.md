# 演示网页视觉与交互设计说明

这份文件讲清楚整套视觉系统是怎么定的，四个页面各自能点什么，
以及假数据到真实数据是怎么切换的。口径以 `app/src/theme/tokens.css` 为准，
组件里不写死颜色。

## 配色怎么定的

整体走深色科技风。背景接近纯黑但带一点蓝，色值 `#05070d`，
面板比背景亮一档到两档，分别是 `#101627` 和 `#161f36`，
让人一眼分清哪里是底、哪里是内容。

主色用高饱和的青色 `#22d3ee`，所有图表主线、激活按钮、推荐参数徽标都从这里取。
辅助色用暖橙 `#fb923c` 做对比，弯度线、下表面压力曲线、误差带、悬停态用它。
通过色用青绿 `#34d399`，警告色用红 `#f87171`，约束是否满足一眼能看出来。
文字分三档，主文字近白，次文字灰蓝，说明文字再暗一档。

所有图表、三维场景、按钮、徽标都从 CSS 变量取色，组件里不出现写死的颜色值。

## 字体和间距怎么定的

中文用系统字体栈，PingFang SC、Microsoft YaHei、Noto Sans CJK SC 依次回退。
数字和拉丁字母用等宽字体 JetBrains Mono 加 Consolas 回退，
让指标卡、参数值、样本名看起来像仪表盘读数。

字号定了五档，12、13、15、18、24 像素，行高分 1.4、1.55、1.65 三档。
说明文字用 12 到 13，正文用 15，面板标题 15 加粗，页面标题 18 到 24。

间距全部用 4 的倍数，4、8、12、16、24、32、48 七档。
圆角两档，6 和 12 像素。阴影两档，发光两档，都只给主色用。

背景加了一点氛围。淡网格线每隔 48 像素一条，再叠两层很淡的径向渐变光斑，
固定在视口不动，不抢内容。

## 动效规则

动效克制但要有。页面切换时内容有一个 240 毫秒的淡入加轻微上移。
参数变化时数值读数有一个 420 毫秒的青色闪光渐变，提示这里变了。
图表本身不跳变，滑块拖动时轮廓、曲线、云图在同一帧里跟着变。
约束通过与否用颜色和图标表达，不用弹窗。
加载中的区块用骨架条加扫光，不用空白。
所有过渡时长只有两档，120 毫秒和 240 毫秒，避免拖泥带水。

## 四个页面各自的交互清单

### 前向预测

- 族别切换，四位族给 M、P、T 三个滑块，五位族给 L、P、T 滑块加 Q 开关。
- 攻角与来流速度两个滑块，每个控件旁边有当前值和一句影响说明。
- 中间翼型形状随参数连续变化，弦线与弯度线可对照。
- 压力曲线一个按钮在闭环弧长序与上下表面弦向叠画之间切换。
- 流场云图四个物理量 u、v、p、nu_t 切换，右侧色标随量程更新。
- 底部四张指标卡随参数实时重算，超限变红并写出超出多少。
- 模型不可用时角标显示示例模型，图注写明原因。

### 降维演示

- 样本选择器支持按名字搜、随机抽、按攻角与雷诺数上下限筛。
- 选中样本显示真实压力曲线、几何形状、官方升力与划分。
- 秩滑块 1 到 8，真实曲线与重构曲线叠画，下面逐点误差带。
- 右侧八条模态，点击某一条把这条模态单独加到重构上看修了什么。
- 累计能量曲线标出当前秩的位置。
- 底部上传区支持拖拽 json 或 csv，解析后给出 POD 坐标与重构误差，
  格式不对时给出中文错误说明。

### 反向设计与对话

- 左侧聊天区，气泡分左右，带时间，输入框在底部，回车发送。
- 右侧三步状态块，解析需求、检索候选、出形状与流场确认，
  发一句话之后依次从等待变进行中再变完成。
- 结果区给四个参数值、翼型形状、压力曲线复核、三项约束通过情况。
- 备选列表点击即切换推荐方案并重新复核压力曲线。
- 右上角设置抽屉里现场填接口地址、模型名称、API key，填完立刻可用。
  徽标显示当前是在线模式还是本地规则模式。

### 成果总览

- 画廊按 figs/index.json 排列，图片加载失败显示图名不显示破图。
- 折中前沿散点，悬停显示四个参数和小翼型缩略图，
  数据库最好与理论上界画成参考线。
- 收敛过程回放，三个种子各一条线，播放按钮加进度条，可以拖着看。
- 数据集体检卡片区，样本数、族别比例、攻角分布、雷诺数分布、
  八个划分的规模都用小图或进度条表示。

## 假数据到真实数据怎么切换

加载顺序是先试真实文件，拿不到再退回假数据，页面不刷新。

`src/data/load.ts` 启动时按顺序探测 manifest.json、cp_basis.json、
grid.json、samples.json、results.json。四个都拿到就是真实模式，
任何一个缺失就整页退回示例模式，保证两套数据不混用。
samples_cp.bin 与 samples_alpha.bin 缺失不致命，退回解析近似，
但缺失的名字会记下来。

页面顶栏有一个角标，绿色写真实数据，橙色写示例数据。
示例模式下旁边有一个重新检测按钮，点一下不刷新页面重新探测一次。

流场与压力模型走另一路探测。b_cp.onnx 与 b_field.onnx 存在就用
ONNX Runtime Web 在浏览器里跑真模型，输出 POD 坐标乘基加均值还原。
模型文件不在或推理出错时不让页面崩，退回解析近似，
并在对应面板标明当前是示例模式和原因。

密钥只在设置面板的内存里。不写 localStorage、sessionStorage、
IndexedDB、Cookie 或文件，页面关掉就没了。
没填接口信息时对话功能自动使用本地规则模式，不联网也能完整演示。
